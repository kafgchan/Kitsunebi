# 朱狐 NPC — 独立レビュー記録

対象: Minecraft 1.21.1 / NeoForge 21.1.259 / GeckoLib 4.9.3。
正本: ワークスペース上位 `仕様書/01_朱狐_キャラクター設定資料.png` と同名制作指示書 v2。
今回の範囲は朱狐 NPC 1体。装備モデル、他3系統、能力、祭壇、レシピは対象外。

## 設計レビュー（GPT-6 Astra / High、読み取り専任）

- 耳を除き約3〜3.5頭身。大頭・短い胴・幅広い袖・裾の広がりを優先する。
- 髪は淡い桜白の短いボブ。前髪、頬横、丸い後頭部、毛先を立体で分離する。
- 赤い大きな目、小さく低めの口、柔らかな頬。通常・微笑・にっこり・真剣・驚き・困りの6表情。
- 狐面は顔を隠さず側頭に配置し、厚み・白地・赤紋・先のある耳・赤リボン・金の房を識別可能にする。
- 白・朱・金の重ね襟、金の肩留めと房、袖の白表地と赤裏地、太い編縄帯を立体化する。微細な刺繍・編み目はUVに担当させる。
- 下衣は中央の濃朱、側方の白布、金縁、裾の赤白模様を区別する。背面の裾と尾を一枚の扇にしない。
- 九尾は個別の根元・中間・先端で構成し、前後のずれを設ける。腰からの接続と裾との隙間を確認する。
- 金は不透明の材質として扱い、未指定の発光・大量パーティクルを追加しない。
- 形状予算は初期目安であり、最終の骨・キューブ数と描画負荷を別途記録する。

## 画像の矛盾・補完

文章には「右側の面」とあるが、正面図の画面右側（キャラクターの左側）を優先する。
髪の隠れた内面、衣装の厚み、尾の根元の間隔は編集可能な立体として補完する。
NPCの九尾版を標準とし、尾数は装備から独立して保持する。将来の段階表示に対応するが、未実装の種族は追加しない。
