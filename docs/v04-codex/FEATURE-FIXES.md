# 装備デザイン・妖術・狐火の色変更（2026-10-19）

- 防具：外へ傾けた小さな狐耳と花飾り、白を主体に朱赤の縁取り、広がる袖、背中の帯リボン。尻尾は細い根元から膨らませ、上向きに曲がる形へ変更。1/3/6/9本とアニメーションを維持。
- 斧：新規アイテムの既定モードを一括伐採へ変更。通常破壊時も破壊前の原木種類を引き継ぐ。Vは照準先を対象にする。自然木の葉の確認、同種の原木、起点以上の高さ・水平半径4、Config上限で伐採範囲を制限。
- ツルハシ：鉱脈モードで破壊前の鉱石種類を引き継ぐ。Vでも照準先の鉱脈採掘を可能にする。コールバック経由と直接発動を分け、起点の二重採掘／耐久二重消費を防止。
- クワ：Vの対象は照準先、照準が外れた場合は足元。単体／3×3／5×5もVで使用可能。耕作・収穫・成長促進の処理件数を6言語のアクションバーと成功音で通知。植え直しは所持種子、なければ周囲の種ドロップを1つ消費。硬度0の作物でも成功1株につき耐久1を消費。
- 修理：7色いずれでも使用可能であることを実処理で検証。GUIは色が循環する見本と「狐火（色指定なし）」のツールチップへ変更。
- 通常クラフト：`kitsunebi:foxfires` アイテムタグと7つの不定形レシピを追加。狐火1個＋対象色の染料1個→対象色の狐火1個。既存色対応に合わせ、水色の狐火（内部cyan）は空色の染料（light_blue_dye）を使用する。他は白・青・緑・紫・橙・赤の染料。

## 実動作の確認

隔離したNeoForge検証サーバーで、通常の `ServerPlayerGameMode.destroyBlock`／クワの使用処理／レシピマネージャーを通して確認：

- 原木5個の一括伐採と耐久5、鉱石8個の鉱脈採掘と耐久8。
- 25マスの耕作、81マスの成長促進、81株の収穫と植え直し。合計耐久消費187。
- 7色それぞれで耐久4,096を修理、7色×7色=49通りの色変更レシピ。
- 既存の面採掘範囲・再帰防止、祭壇の原子的出力、スロープ移動の検証も成功。

検証ソース：`neoforge/.../verification/EquipmentFeaturesVerifier.java`。GUIと防具の描画は専用クライアントの `altar-gui-3.png`／`altar-gui-4.png` で確認。Fabricはコンパイルと配布用JAR生成を確認。Fabricでのゲーム内実動作は未検証。

操作：Shift+Vでモードを切り替え、Vで発動、Bで妖術ON/OFF。以前のアイテムに「単体」の選択が保存されている場合は一括モードへ切り替える。
