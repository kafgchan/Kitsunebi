# 空中歩行：スニーク＋ジャンプ仕様

2026-10-19。旧「1回目ジャンプ→空中で2回目」の状態機械を置換。

- 狐火の足袋を装備し、足袋の妖術がONのとき、スニーク＋ジャンプで空中歩行を開始／解除。キーの押す順序は問わない。
- 地上でも空中でも切り替え可能。一度切り替えたら、両キーを完全に離すまで次の切り替えを受け付けない。しゃがみ続けながらジャンプを押し直しても連続解除しない。通常ジャンプでは切り替わらない。
- 空中歩行中：ジャンプ長押しで上昇、スニーク長押しで下降。スニーク中にジャンプを新しく押すと解除を優先。両方を押している間は上下移動させない。上下のキーを離すと、その高度で待機する。
- 開始時の押し残しを下降入力にしないため、開始後に両キーを一度離してから上下操作を受け付ける。上昇は毎秒3.6ブロック、下降は毎秒6ブロック。
- 水平ダッシュはバニラと同じ速度属性補正を使い、歩行の約1.3倍。空中でもダッシュキーから開始できる。
- 上下入力は変更時と10tickごとの更新をサーバーへ送り、範囲・装備・有効状態・スニークを検証。入力更新が途切れた場合は上下移動を停止する。
- 足袋の妖術ON/OFFはG、ツールの妖術ON/OFFはBで独立。Vは発動専用、Nは次のモード、Mは前のモード。各キーは操作設定で変更可能。足袋OFFで空中歩行を解除する。
- サーバーが装備・妖術状態・スニーク・生存・飛行等を検証。承認後に所有者へS2C状態パケットを送り、重力停止を同期する。水平移動／停止／空中待機をクライアントでも同じ方式で処理。実ブロックは置かない。
- 装備解除、妖術OFF、死亡、ログアウト、ディメンション変更、実地形への着地、飛行・滑空・騎乗・溶岩への移行で解除（水・泡では維持）。別機能が既に重力を無効化している場合は開始しない。
- チャット・GUI中は切替キーを無効にし、承認済みの空中歩行はその場で待機する。
- 操作結果の表示は6言語。周囲への足元パーティクルは既存ConfigのON/OFFに従う。

## 検証範囲

隔離NeoForgeサーバーの `AirWalkVerifier` で、足袋なし・スニークなし・妖術OFFの拒否、スニークでの開始／解除、B切替、80回の実際の `Player.travel` による水平移動と高度維持、20tickのGUI相当待機、解除後の落下、装備解除、地形への着地、ログアウト相当の解除、死亡、別機能の重力所有、クリエイティブ飛行との競合を確認。

クライアント移動処理は共通クラスを検証サーバー上で呼んで検証。実クライアントからキー入力し、ネットワーク越しに往復する通し操作は未検証。両ローダーのコンパイル・配布JAR生成を確認。

上下操作は、20tickの上昇と12tickの下降、キー解放後の10tickの高度維持、不正な上下値の拒否、スニークなしでの下降要求の拒否、両キー同時押しの上下移動抑止を検証。さらに、両キー解放による切替再受付、片キーだけの解放・長押し・GUI後の押し残しで連続切替しないこと、開始時の下降抑止、ダッシュ／歩行の速度比1.3と歩行への復帰を検証した。
