# Geminiイメージ図に合わせた再制作

ユーザー提供の `sources/gemini-shrine-reference.png` を造形の基準に使用。再生成は `generate-shrine-outfit.py` で行う。旧 `generate-equipment.py` の単独実行は今回のデザインを上書きするため行わない。

## 反映内容

- 頭飾り：赤い先端と白い内側を持つ狐耳、横に添える小さな狐面。
- 胴：白地に深紅の合わせ襟、肩と背中の深紅の布、金の胸飾り、金の房と紐、長い袖・前裾。
- 脚：黒と灰の縦ひだの袴、金の帯紐・結び目・下がり房。
- 足：白い足袋、深紅の鼻緒、暗い木色の薄い下駄。
- 尻尾：白毛と深紅の先端。1/3/6/9本の扇形配置と揺れを継承。
- 狐面：御守り風の小面と共通した白・深紅・黒の立体造形。既存の内部IDと装備表示変換を維持。
- 御幣：漆色の柄、金の金具・先端、立体的に折れた白い紙垂。

装着モデルとアイテムモデルを同じ部品データから作成。色は参考図の白・深紅・金・黒を基準としたコード生成の128×128パレット。参考画像のピクセルを防具へ貼り付ける方式ではない。装備能力・操作・レシピは変更していない。

## 検証

6つのアイテムモデル（頭・胴・脚・足・狐面・御幣）の座標範囲と部品の正体積を検査。NeoForgeの専用クライアントでアイテム、装着パーツ、1/3/6/9本の尾と実際の防具描画フックを確認。Fabricのコンパイルと配布JAR生成も成功。

`shrine-reference-game-preview.png` はゲームレンダラーの確認画像。頭部の無地キューブは配置確認用マネキンで、実際のプレイヤーの顔・スキンは変更しない。
