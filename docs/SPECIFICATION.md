# Kitsunebi（狐火）— Mod 仕様書

旧竹Mod（Bamboo Mod）に登場した「狐火」に着想を得た、Minecraft 1.21.1 向けの独立した軽量・高品質な光源Modです。

## 1. 主な特徴

### 1-1. 透明照明・すり抜け
- **当たり判定なし**: プレイヤーやMob、矢などの飛翔体は完全にブロックを通り抜けます。
- **水中設置（Waterlogged）対応**: 水中にも自然に設置でき、水流をせき止めません。
- **手持ち時の回収**: 手に狐火または「狐火の御幣」を持っている時のみ当たり判定（選択枠）が現れ、左クリック一撃で回収できます。

### 1-2. 手持ち時の狐火可視化（パーティクル演出）
- **周囲の狐火をハイライト**: プレイヤーがメインハンドまたはオフハンドに「狐火」また「狐火の御幣」を持っている間、周囲10m以内の透明な狐火の位置から各色の淡い光パーティクルがふわふわと立ち上ります。
  - **白**: エンドロッドの白いきらめき
  - **青**: ソウル炎の蒼い火の粉
  - **水色**: グロウの淡い発光粒子
  - **緑**: 村人のハッピーきらめき粒子
  - **紫**: 魔女の魔法粒子
  - **橙・赤**: 揺らめく炎の粒子
- 手から離すとパーティクルは即座に消失し、完全な透明に戻ります。

### 1-3. 空中設置機能
- 空中で右クリックすることで、視線先の空間（3.5ブロック先）に直接狐火を配置できます。足場のない吹き抜けや天井への照明配置に最適です。

### 1-4. 狐火の御幣（専用道具）
- 狐火に対して右クリック（またはShift右クリック）することで、以下の状態を切り替えられます：
  - **表示モード**: 透明（非表示） ⇔ 常時表示（炎モデル）
  - **光源強度**: 発光（Level 15） ⇔ 消灯（Level 0）

### 1-5. 7色のカラーバリエーション
- 白 (White)
- 青 (Blue)
- 水色 (Cyan)
- 緑 (Green)
- 紫 (Purple)
-橙 (Orange)
- 赤 (Red)

それぞれ独立したブロックおよびアイテムとして提供され、クリエイティブタブ「Kitsunebi」から利用可能です。

## 2. v0.2 追加機能仕様：透明建築システム

透明建築システムは、秘密基地、隠し扉、アスレチック、建築の足場や見えない手すりなど、高度な建築とギミックを可能にする機能拡張です。

### 2-1. 分類と可視化

- **A：建築用狐火ブロック (`ArchitecturalKitsunebiBlock`)**:
  - 通常不可視・衝突判定なし・通り抜け可能。
  - 既存の光源狐火（装飾・照明）とは別枠の建築専用ブロック。
  - 狐火アイテム／御幣／狐火ゴーグルにより可視化。
- **B：幻影ブロック群 (`Phantom Blocks`)**:
  - 通常不可視だが物理的に存在し、衝突・設置・レッドストーン入出力等の機能を完全保持。
  - 狐火アイテム／御幣／狐火ゴーグルにより可視化。
- **可視化と判定の分離**:
  - 可視化（パーティクル、アウトライン、モデル描画）はクライアント側で判定。
  - 衝突判定・レッドストーン・権限はサーバー側で管理。

### 2-2. 幻影ブロックの種類

1. **幻影フルブロック (`PhantomBlock`)**: バニラの完全な立方体形状。
2. **幻影横ハーフブロック (`PhantomSlabBlock`)**: バニラハーフ準拠（下付き・上付き・ダブル）。
3. **幻影縦ハーフブロック (`PhantomVerticalSlabBlock`)**: 高さ1ブロック、厚さ0.5ブロックの垂直板状。4方向（東西南北）の設置に対応。
4. **幻影横クォーターブロック (`PhantomQuarterSlabBlock`)**: 高さ4/16、幅・奥行16/16。上下方向に4段階の配置位置（`LAYER: 0..3`）を持つ薄型床・段差用ブロック。
5. **幻影縦クォーターブロック (`PhantomVerticalQuarterBlock`)**: 高さ16/16、厚さ4/16。東西南北の軸・向きと厚さ方向の4段階位置（`LAYER: 0..3`）に対応する薄型壁用ブロック。
6. **幻影太い柵 (`PhantomWallBlock`)**: バニラの石の塀（Wall）相当の柱・接続形状と衝突判定。東西南北の接続・高さ変化などのBlockStateに準拠。
7. **幻影細い柵 (`PhantomFenceBlock`)**: バニラの木のフェンス（Fence）相当の柱・接続形状と衝突判定。東西南北の自動接続に対応。
8. **幻影扉 (`PhantomDoorBlock`)**: バニラの木の扉相当の開閉動作。透明な隠し扉を実現。
9. **幻影レッドストーン部品**:
   - **感圧板 (`PhantomPressurePlateBlock`)**: プレイヤー・Mobの踏み判定を検知する不可視感圧板。
   - **ボタン (`PhantomButtonBlock`)**: 壁・床・天井に設置可能な不可視ボタン。
   - **レバー (`PhantomLeverBlock`)**: 不可視レバー。
10. **幻影階段 (`PhantomStairsBlock`) ＆ 幻影スロープ (`PhantomSlopeBlock`)**:
    - **高・中・低の3サイズを共通規格化**:
      - **高 (High)**: 最大高さ16/16、奥行16/16。
      - **中 (Mid)**: 最大高さ8/16、奥行16/16。
      - **低 (Low)**: 最大高さ8/16、奥行8/16（低の縦は奥行きとして計算）。
    - **内角・外角自動接続（バニラ階段準拠）**:
      - 高・中・低の全サイズに対して `STRAIGHT`, `INNER_LEFT`, `INNER_RIGHT`, `OUTER_LEFT`, `OUTER_RIGHT` の5形状を持たせ、隣接ブロックの向き・形状と設置／隣接更新をもとに自動判定。
      - スロープは各角形状に対応する専用VoxelShape（滑らかな階段状近似）を採用。

### 2-3. 狐火の仮面 (`KitsunebiGogglesItem`)

- 正式名称は「狐火の仮面」（旧称：狐火ゴーグル）。
- 建築支援用の頭装備。装着中は周囲の狐火ブロック・幻影ブロックを継続可視化。
- 通常の頭スロットに装備可能。防御力0、耐久値なし。
- **外部アクセサリーAPI連携（任意依存）**:
  - **NeoForge**: Curios の Head スロット連携。
  - **Fabric**: Accessories の頭部アクセサリースロット連携。
  - 外部MODが未導入でもバニラの頭防具スロットで完全動作。

## 3. v0.3 追加仕様：製作・回収・ライセンスシステム

### 3-1. ブロック回収仕様（ドロップ条件）

対象：狐火（7色）、狐火ブロック、幻影ブロック全種類。
- **狐火の御幣による回収**: 御幣で対象ブロックを破壊した場合、仮面の有無にかかわらず常に対応アイテムをドロップ。
- **狐火の仮面＋シルクタッチによる回収**: 狐火の仮面を装備し、シルクタッチ付き道具で対象ブロックを破壊した場合、対応アイテムをドロップ。
- **それ以外の破壊**: 素手、通常道具、シルクタッチのみ、仮面のみ、クリエイティブ破壊ではドロップしない（消失）。
- 判定はサーバー側で統一管理し、不正増殖や二重ドロップを防止。

### 3-3. 専用作業台「狐火の祭壇（Altar of Kitsunebi）」システム

#### GUI・操作仕様
- **方式**: 素材投入＋形状・色カスタマイズ方式（C方式）。
- **数量指定**: プリセットボタン（1, 2, 4, 8, 16, 32, 64個）＋ スライダー（1〜64個、1個刻み）。完成アイテム個数に連動。
- **カテゴリ**: 狐火（7色）、狐火ブロック、幻影建材（全形状）。
- **幻影建材**: 色選択なし。形状・サイズ・種類のみ選択。

#### レシピ定義と必要素材比率

1. **狐火（7色）**:
   - 1個あたり: （輝くイカスミ×1 または グロウストーンダスト×1）＋ アメジストの欠片×1 ＋ 竹×4 ＋ ラピスラズリ×2 ＋ 各色染料×1
   - 染料対応: 白→白色, 青→青色, 水色→空色, 紫→紫色, 緑→緑色, 橙→橙色, 赤→赤色の染料。
   - 代替発光素材の消費順: スロット番号順（左上から右下）。
2. **狐火ブロック**:
   - 1個あたり: 狐火×8（7色のどれでも可、混在可、スロット順消費）＋ アメジストブロック×1。
3. **幻影フルブロック**:
   - 1個あたり: 狐火ブロック×1 ＋ （スライムブロック または ハチミツブロック 計4個、混在可） ＋ （ソウルサンド または ソウルソイル 計4個、混在可）。
4. **幻影建材の形状加工比率**:
   - **横ハーフ / 縦ハーフ**: 幻影フル×3 → 6個
   - **横クォーター / 縦クォーター**: 幻影フル×3 → 18個
   - **高階段 / 高スロープ**: 幻影フル×6 → 4個
   - **中階段 / 中スロープ**: 幻影ハーフ（横・縦混在可）×6 → 4個
   - **小階段 / 小スロープ**: 幻影クォーター（横・縦混在可）×6 → 4個
   - **壁**: 幻影フル×6 → 6個
   - **扉**: 幻影フル×6 → 3個
   - **感圧板**: 幻影フル×2 → 1個
   - **ボタン**: 幻影フル×1 → 1個
   - **フェンス**: 幻影フル×6 → 6個
   - **レバー**: 幻影フル×1 ＋ 棒×1 → 1個
